# Первые шаги

## Текущий статус

- [x] Детерминированный GDScript walking skeleton.
- [x] 20 NPC, 3 места и 2 организации.
- [x] Person, Relationship, Fact, Knowledge и SocialEvent.
- [x] Разделение мировой истины и наблюдаемого знания.
- [x] Скрытые связи Anna → Sergey → Maria.
- [x] Визуальный экран разговора, цели и социального маршрута.
- [x] AskAbout, AskFavor и preconditions для AskIntroduction.
- [x] DecisionEngine, CommunicativeAct и template/Groq Social Renderer.

## 0. Walking skeleton

Цель: проверить запуск проекта Godot и детерминированный headless-тест ядра.

Критерий готовности:

- одинаковый seed и последовательность команд дают одинаковый checksum;
- главная сцена создаёт мир и выполняет `advance`;
- весь сценарий запускается без окна одной командой.

## 1. Минимальная модель мира

Добавить 20 NPC и три места: Office, Cafe, Apartment. Идентификаторы должны
быть числовыми, а состояние ядра не должно зависеть от Node и SceneTree.

Минимальные компоненты:

- Person;
- Relationship;
- Fact;
- Knowledge;
- Event.

## 2. Первые социальные действия

Реализовать строго структурированные команды:

- AskAbout;
- AskFavor;
- AskIntroduction.

Сначала действие проверяет preconditions, затем DecisionEngine возвращает
решение и числовое объяснение. Текстовая реплика пока создаётся шаблоном.

## 3. Сценарий Aurora Party

Задать минимум три достижимых социальных пути. Planner используется только
для проверки достижимости и не сообщает путь игроку.

## 4. UI вертикального среза

После стабилизации ядра добавить:

- список доступных действий;
- окно разговора;
- карту известных игроку социальных связей;
- debug inspector решения NPC.

## 5. LLM renderer

Подключать только после работающего template renderer. LLM получает готовый
CommunicativeAct и никогда не изменяет состояние симуляции.
